# Data Structure & Graph Analyzer

## Project Description

The Data Structure & Graph Analyzer is a Java console-based application developed for the CIT300 Data Structures and Algorithms module.

The system demonstrates the implementation of fundamental data structures and algorithms including Arrays, Stacks, Queues, Linked Lists, Searching Algorithms, Graphs, Breadth First Search (BFS), Depth First Search (DFS), and Performance Comparison techniques.

The application follows Object-Oriented Programming (OOP) principles and provides a menu-driven interface for users to interact with the implemented data structures.

## Instructions for Running the Program

### Compile the Program

```bash
javac src/**/*.java src/Main.java
```

### Run the Program

```bash
java -cp src Main
```

### Using the Program

1. Run the application.
2. Select a menu option.
3. Perform the required operation.
4. Follow on-screen instructions.
5. Choose Exit to terminate the program.
